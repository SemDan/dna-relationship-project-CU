# Проект: Анализ родства организмов по ДНК

Этот проект посвящён анализу генетических последовательностей различных организмов и оценке их эволюционной близости на основе сходства ДНК.

Основная идея проекта — сравнить гены разных организмов и построить **таблицу родственности**, отражающую степень их сходства.

Проект реализован на Python и организован как модульный пайплайн.

# Этап 1 — Чтение ДНК и анализ сходства

Первый этап проекта включает:

1. Чтение ДНК последовательностей из `.fna` файлов  
2. Извлечение названия организма из заголовков FASTA  


Основная гипотеза:

> Чем длиннее общая подпоследовательность ДНК у двух организмов, тем ближе их эволюционное родство.

---

# Входные данные

Используется **10 генетических последовательностей реальных организмов**.

Примеры видов:

- Homo sapiens
- Mus musculus
- Bos taurus
- Canis lupus familiaris
- Felis catus
- Equus caballus
- Mesocricetus auratus
- Danio rerio
- Drosophila melanogaster
- Caenorhabditis elegans

Каждый организм хранится в отдельном `.fna` файле.

Файлы имеют формат **FASTA**.

Пример:

> NC_037345.1 RPL18 [organism=Bos taurus]
    ATGCGATCGATCGATCGATCG...


---

# Стратегия обработки файлов

Некоторые `.fna` файлы могут содержать **несколько FASTA-записей**.

Чтобы получить одну последовательность для организма, используется следующая стратегия:

1. Считываются **все FASTA записи**
2. Из заголовка извлекается `[organism=...]`
3. В качестве представителя организма выбирается **самая длинная последовательность**
